# 实施决策

- 技术栈：React 19、TypeScript 5.9、Vite 7、Zustand 5、Vitest 3。Node 24 可运行。页面状态放在存档和内存里，不使用会在刷新时 404 的路径。
- 阶段 0—3 只开放青禾村、山雨破庙、雾隐竹林。州内其余地点不做成可点的空按钮。
- 基础流派先做剑修与火修。体修、仙魔道路、筑基试炼和金丹留到阶段 4。筑基材料的同时扣除规则已有纯函数，玩家界面不提供筑基按钮。
- 破庙三个选择的关系、信物不同，但都给予 8 点修为；沈砚传授 12 点；第一次胜利走完引气试炼把试炼修为补到 30。这样正常走完可以在一次游玩里达到 50 点并引气。
- 试炼胜利的修为补齐只发生一次。重复进入不再提供这段突破修为。
- 安全撤离在休息处和首领前空地，带回全部本局收获。暂停里的放弃，以及战斗失败，按一半灵石、一半材料和一半本局修为结算。
- 剧情信物获得时立刻写入永久背包。广告接口存在，但没有真实广告位，结算页不显示广告按钮。洞府离线产出只保留计算函数，不显示可领取入口。
- 音效没有素材，设置里的音效按钮禁用并说明原因。
- 开发工具只在开发构建加载，用来准备引气条件，不代替正常战斗结算。
- 场景是原创临时 SVG，不是完成的高精度原画。
