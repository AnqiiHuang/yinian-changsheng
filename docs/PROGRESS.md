# 阶段进度

当前完成的是第一轮 A：手机体验与美术基础。第二轮、第三轮没有开始。线上 Pages 没有在本轮发布。

## 玩家现在可以做的事

- 战斗底部一直留着气血、灵力和攻击、守御、施术。攻击写明无消耗，守御写明减伤与回灵，灵力不够时施术禁用并写明还差多少。
- 剑意显示为 n/5，并说明当前造化会不会在施术前消耗它。灼烧会写成层数、剩余回合和每回合伤害。护盾和气血分开。敌方下一手写在意图条上。每一手结束后有一句伤害和气血变化。
- 首页只在顶栏放姓名、境界和地点，下面是修为进度、当前目标和一个主操作。没打完的历练显示“继续历练 · 第 X 处”。
- 建角分两步：先名字和外形，再出身、天赋和确认。返回不会丢掉已选内容。
- 剧情默认整段显示，设置里可以改成逐字，逐字时可以显示全文。
- 行囊按类别区分永久物品和本局战利，已学会的功法、心法标出装备状态。地图用纸面标出青禾村、破庙和竹林，竹林未开放时不能点进去。
- 结算按带回、封存、未用补给、没有带回和接下来排列，领取按钮只入账一次。
- 引气时记下突破前属性。突破后的对比、养元经和竹林开放由规则测试覆盖。浏览器这次没有把试炼胜利走到引气仪式。
