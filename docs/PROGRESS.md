# 阶段进度

当前停在阶段 0—3 的可玩样本。阶段 4 还没开始。

## 已可玩

- 开场、建角、青禾村主界面、青岚地图（青禾村、山雨破庙、雾隐竹林）。
- 雨夜破庙三选一，侧殿选择剑修或火修。
- 三节点引气试炼，十节点雾隐竹林，局内造化、补给、休息、封存、安全撤离和放弃。
- 凡人到炼气的首次突破。筑基按钮保持关闭，并说明原因。
- 胜利、撤离、战败的结算与一次性领取。刷新后回到未领完的结算或未打完的战斗。

## 本轮验证

- `npx tsc --noEmit` 通过。
- `npx vitest run`：9 项通过。覆盖同种子路线、空事件池回退、付不起的选择、试炼胜负与撤离、失败不扣突破材料、护盾与灼烧、存档损坏后的备份、广告幂等。
- `npm run check:content`：3 项通过。
- `npm run build` 通过。产物约 351 kB（gzip 112 kB）。正式包里没有“备好引气”。
- 浏览器在 320、360、390、430 宽下没有横向溢出。主战斗按钮高度 52px。
- 浏览器实玩：建角林晚 → 破庙选择 → 松风剑诀 → 试炼胜利 → 双击领取后灵石 20 到 40、修为 20 到 50，只入账一次 → 突破到炼气初期 → 再次进入竹林，完成一个事件、一次造化和一场重复战斗。战斗中刷新后仍是同一场胜利。

## 已知问题

- 场景是临时矢量图，不是完成的水墨原画。
- 没有音效，设置里的音效按钮禁用。
- 浏览器没有把竹林打到雾骨山魈，也没有在浏览器里再走一遍撤离和战败。这两条结算由规则测试覆盖。
- 开发服务里有“测”按钮。正式构建不包含它。
