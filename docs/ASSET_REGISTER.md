# 资产登记

本轮没有可用的位图生成。下列文件都是项目内原创临时矢量，不是完成的水墨原画。替换时保持手机横幅约 390×180、敌人条约 390×120，单张压到 250KB 以内，使用 WebP 或 AVIF，不要把文字画进图里。

位图提示词基底：原创中国幻想修仙游戏场景，淡墨晕染与低饱和青绿山水，细腻纸本质感，近中远三层空间，画面安静。适合手机顶部横幅，主体在侧边或下三分之一，留出干净空间。无文字、无界面、无水印、无现代建筑。
